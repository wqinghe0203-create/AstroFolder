       🌌 AstroFolder - 星图视界 (文件夹星系透视客户端)

【极速使用指南（发给同事直接用）】

方式一：【网页版 · 0安装0配置】（推荐发送给任何同事）
  👉 直接把本目录下的【AstroFolder.html】发给同事（或双击【run_web.bat】）；
  👉 无论手机、平板、还是任何电脑（Chrome / Edge 浏览器），双击打开即可使用；
  👉 点击顶部【选择文件夹】，即可 360° 展开任意目录，查看全部文档并无限下钻。

方式二：【独立桌面客户端（免安装绿色版）】
  👉 将整个【AstroFolder】文件夹打包为 zip 发给同事；
  👉 同事解压后，双击【run.bat】即可秒级唤起桌面客户端；
  👉 也可直接进入【bin\AstroFolder】目录双击【AstroFolder.exe】；
  👉 无需配置 Python 环境，绿色独立运行。

------------------------------------------------------------------------
【核心交互与操作手势】
------------------------------------------------------------------------
1. 鼠标悬停（Hover）：
   - 悬停在一级文件夹卡片上，自动平滑发散出其二级子文件与文档星轨；
   - 悬停在长文件名上自动浮现全息完整名称气泡。

2. 单击下钻（Click）：
   - 单击任意文件夹，瞬间进入该目录，向外辐射展示其全部文档与子项；
   - 支持深层无限级穿透！

3. 返回上级：
   - 单击正中央的【CURRENT WORKSPACE】核心主卡片即可回退一级；
   - 或点击顶部的【面包屑导航栏】直接跳回任意上层路径。

4. 启动打开文件（桌面版专属）：
   - 桌面客户端中双击任意文档（Word/Excel/PDF/代码），直接调用系统默认软件打开。
