【最新重大升级】
1. 🧠 默认引入【思维导图模式】（零重叠，杜绝覆盖）：
   - 解决多文件夹或多文档时上下层覆盖重叠问题；
   - 采用右向树状包围盒层级分布，每个分支拥有专属垂直排布空间，100% 互不遮挡；
   - 顶部提供「🧠 树状导图」、「⚖️ 双向导图」、「🪐 星轨雷达」三种布局模式一键切换。
2. 🔍 【全称直接显现】（杜绝省略号截断）：
   - 卡片宽度基于真实文本精确计算动态自适应包裹；
   - 一眼看清完整文件名（如《安全生产管理台账.xlsx》），省去挨个鼠标悬停查找的时间！
3. 🖐 【无限画布拖拽与缩放】：
   - 鼠标按住空白画布即可自由拖拽平移；
   - 滚轮纵向滚动浏览，按住 Ctrl + 滚轮平滑缩放；顶部提供「🎯 居中」一键复位。

------------------------------------------------------------------------
【极速使用指南（发给同事直接用）】
------------------------------------------------------------------------

方式一：【网页版 · 0安装0配置】（推荐发送给任何同事）
  👉 直接把本目录下的【AstroFolder.html】发给同事（或双击【run_web.bat】）；
  👉 无论手机、平板、还是任何电脑（Chrome / Edge 浏览器），双击打开即可使用；
  👉 点击顶部【打开本地文件夹】，即可横向全息展开任意目录，查看全部长文件名并无限下钻。

方式二：【独立桌面客户端（免安装绿色版）】
  👉 将整个【AstroFolder】文件夹打包为 zip 发给同事；
  👉 同事解压后，双击【run.bat】即可秒级唤起桌面客户端；
  👉 也可直接进入【bin\AstroFolder】目录双击【AstroFolder.exe】；
  👉 无需配置 Python 环境，绿色独立运行，双击文件直接调起本地 Office/WPS/VSCode 编辑！

------------------------------------------------------------------------
【核心交互与操作快捷方式】
------------------------------------------------------------------------
1. 鼠标悬停（Hover）：
   - 鼠标滑过节点卡片，关联层级连线高亮流光，非关联连线智能虚化。

2. 单击（Click）：
   - 单击文件夹展开其内部子项或深入下钻；
   - 点击顶部面包屑胶囊可直接跳转到任意历史路径。

3. 画布拖拽与滚轮（Pan & Zoom）：
   - 按住鼠标左键或右键拖拽空白区域，可自由平移整个导图；
   - 鼠标滚轮纵向滑行；Ctrl+滚轮全局缩放；点击顶部「🎯 居中」瞬间重置视野。

4. 启动打开文件（桌面版专属）：
   - 桌面客户端中双击任意文档（Word/Excel/PDF/代码），直接调用本机关联的本地软件原文件打开。
