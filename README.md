# 🌌 AstroFolder (星图视界)

> **思维导图与星系拓扑结合，全景俯瞰你的文件夹与文档。**  
> 告别枯燥扁平的文件树与繁琐的翻找！AstroFolder 是一款将文件夹层级结构转化为 **思维导图树状拓扑** 与 **360° 极坐标星系** 的新一代文件透视工具。遵循 Linear / Vercel 现代精工设计规范，提供双运行形态支持（零环境网页免安装版 + 独立免配环境桌面客户端）。

---

## ✨ 核心特性

- 🧠 **思维导图横向树状拓扑（Mind Map Tree - 默认）**：
  - 核心主工作区居左，各级文件夹与子项严格按纵向包围盒树状右向展开；
  - **100% 杜绝上下层重叠覆盖**：每个子分支具有独立的垂直空间槽位，多文件、多文件夹纵向整齐排布，互不遮挡；
  - 支持 **「🧠 树状导图」**、**「⚖️ 双向导图」**、**「🪐 星轨雷达」** 三种视觉布局模式自由一键切换。
- 🔍 **全称直接显现（Zero-Truncation Full Name Display）**：
  - 卡片宽度基于真实文本物理像素精确测量动态自适应包裹；
  - **杜绝任何省略号截断（如 `安全生产...xlsx`）**，一眼看清完整长文件名与真实扩展名，无需鼠标逐个悬停翻找，真正实现「一目了然」！
- 🖐 **自由画布平移与缩放（Infinite Canvas Pan & Zoom）**：
  - 鼠标左键/右键按住空白画布自由拖拽平移；
  - 鼠标滚轮纵向滑行浏览，Ctrl + 滚轮平滑缩放视图，并支持一键「🎯 居中」重置视野。
- 🔍 **全深度穿透下钻（Infinite Deep Drill-down）**：
  - 支持任意深度的文件夹点击下钻与层级跳转，实时响应，完整呈现深层所有子文件夹与全部文档（`.docx`、`.xlsx`、`.pdf`、代码等）。
- 🎨 **Apple & Linear 现代工程美学**：
  - 弥散柔和多层阴影、毛玻璃卡片、微发光渐变微边框、低饱和度格式微标（`DOCX`、`XLSX`、`PDF`、`CODE` 等）。
- 🚀 **双运行形态支持**：
  - **网页极速免安装版 (`AstroFolder.html`)**：单文件纯前端（HTML5 Canvas + File System Access API），任何现代浏览器（Edge / Chrome）双击秒开，0 依赖、0 安装、跨平台！
  - **独立桌面客户端 (`AstroFolder.exe`)**：内置微型 Python 运行时环境，支持双击直接在 Windows 本地 Word/Excel/WPS 中打开原文件并实时编辑保存。
- 👁️ **全息快速预览（Quick Look）**：
  - PDF 文件：原生浏览器阅读器直接打开；
  - 图片文件：高保真灯箱大图无损全屏预览；
  - 文本/代码：等宽字体行号代码阅读器；
  - Office 文档：全息元数据卡片 + 一键呼起本地软件查看。

## 🚀 极速上手

### 方式一：网页免安装版（最推荐，零环境配置）
1. 双击运行 `run_web.bat`（或直接双击用 Edge/Chrome 打开 `AstroFolder.html`）；
2. 点击页面顶部导航栏的 **「📂 打开本地文件夹」**；
3. 选入电脑中的任意工程或需求目录，即可一览无余地查阅全部文件全称！

### 方式二：独立桌面客户端（绿色免安装）
1. 双击运行根目录下的 `run.bat`（或进入 `bin/AstroFolder` 目录双击 `AstroFolder.exe`）；
2. 客户端秒级弹出，无需安装配置 Python 环境；
3. 双击任何文件，直接调用 Windows 关联的本地应用（如 Word、Excel、VS Code）打开原文件。

## 🎮 常用交互手势

| 操作手势 | 触发交互 | 说明 |
| :--- | :--- | :--- |
| **鼠标悬停 (Hover)** | 动态高亮与子分支发散 | 悬停在文件夹上，平滑点亮该分支与下属连线流光 |
| **单击文件夹 (Click)** | 展开分支 / 下钻进入 | 单击展开直属子项；再次深入进入目录，中心卡片自动更新 |
| **画布拖拽 (Drag)** | 全景平移画布 | 鼠标按住空白画布任意方向拖拽平移，浏览超大目录树 |
| **鼠标滚轮 (Wheel)** | 上下滑动 / 缩放 | 滚轮上下滑动浏览；按住 Ctrl 滚动可平滑缩放全局视野 |
| **双击文件 (Double Click)** | 打开/预览文件 | 桌面版直接调起本地软件打开；网页版提供高清预览或一键调起 |
| **单击顶部居中 (Center)** | 视野快速居中 | 点击顶部「🎯 居中」按钮，瞬间复位视角 |
| **点击顶部面包屑** | 精准路径跳转 | 任意点击上级路径胶囊，快速回溯 |

## 📁 目录结构

```text
AstroFolder/
├── AstroFolder.html                # 核心网页版（单文件纯前端，零依赖）
├── AstroFolder_网页免安装版.html    # 中文命名备份
├── run_web.bat                     # 一键唤起网页版
├── run.bat                         # 一键唤起独立桌面版
├── 使用说明_README.txt              # 纯文本使用手册
├── scripts/                        # 桌面客户端源码
│   ├── cyber_radial_peek.py        # 极坐标核心绘制与交互主程序 (Tkinter)
│   └── explorer_hook.py            # Windows 资源管理器前台探测模块
└── bin/                            # 独立绿色免安装运行时 (PyInstaller)
    └── AstroFolder/
        ├── AstroFolder.exe         # Windows 独立引导程序
        └── _internal/              # 内置微型 Python 运行时与依赖库
```

## 🛠️ 技术栈

- **前端渲染**：HTML5 Canvas 2D, File System Access API, CSS3 Glassmorphism (Backdrop Filter), Web Audio API (交互声效反馈)
- **桌面客户端**：Python 3.12, Tkinter Canvas Engine, Win32 API, PyWin32 Shell COM
- **构建打包**：PyInstaller Standalone Runtime
